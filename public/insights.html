Time on page

Measured in the browser and sent when the page is closed. Background tabs do not count — the clock stops when the page is hidden. One reading counts for at most 10 minutes; past that it is a tab left open, and it still pulls the average up.

Raw request logs

Per-request detail is not in D1 — storing every request would triple the write cost for data that is rarely read. Two places have it:

Live tail

Every request as it happens, including console output and uncaught errors. Best for debugging something happening right now.

npm run tail

Analytics Engine

One row per request, kept for 90 days, queryable with SQL. Best for a question these rollups cannot answer.

SELECT blob1 AS path, count() AS hits,
       avg(double1) AS avg_ms
FROM flaky_requests
WHERE timestamp > now() - INTERVAL '7' DAY
  AND double3 = 0
GROUP BY path ORDER BY hits DESC
